Chatbot Loja Fitness

Chatbot para atendimento de uma loja fitness, desenvolvido com Node.js e integrado à API Gemini.

Como rodar o projeto

1. Entre na pasta "backend".
2. Instale as dependências:

npm install

3. Crie um arquivo ".env" com sua chave da API Gemini:

GEMINI_API_KEY=sua_chave_aqui

4. Inicie o servidor:

node server.js

Depois, acesse o projeto pelo navegador.
